# Business-Performance-Operations-Analytics
This project analyzes Brazilian e-commerce data to understand business performance, sales trends, order fulfillment, and customer satisfaction. The objective is to transform raw data into meaningful business insights using Python, Excel, and Power BI.

Tools & Technologies

Python: Pandas, NumPy, Matplotlib, Seaborn

Excel: Formulas, PivotTables, MIS reporting

Power BI: Interactive dashboards, DAX measures, data modeling

Data Modeling: Fact and dimension tables, relationships

Dataset

The project uses the Olist Brazilian E-Commerce Public Dataset.

Datasets used:

olist_orders_dataset.csv – Order status and timestamps

olist_order_items_dataset.csv – Products, item prices, and freight

olist_customers_dataset.csv – Customer information

olist_products_dataset.csv – Product details

olist_order_payments_dataset.csv – Payment information

olist_order_reviews_dataset.csv – Customer review scores

Project Workflow

1. Data Cleaning and Preprocessing

Imported six CSV datasets using Pandas.

Examined dataset dimensions, data types, missing values, duplicates, and outliers.

Converted date columns to datetime format.

Corrected data types and prepared datasets for analysis.

2. Exploratory Data Analysis (EDA)

Performed exploratory analysis to understand:

Order status distribution.

Monthly sales trends.

Customer review score distribution.

Order and product performance.

Freight and payment patterns.

3. Excel MIS Reporting

Created a monthly MIS report with the following metrics:

Month

Delivered Orders

Item Sales (R$)

Freight (R$)

Late Delivery Percentage

4. Power BI Dashboard

Developed an interactive Power BI dashboard to analyze business performance using relevant KPIs, charts, and data relationships.

The dashboard focuses on business performance and sales analysis. Delivery performance dashboard development is not yet completed.

5. Data Modeling

Established relationships between the orders, order items, customers, and products tables to support business reporting and analysis.

Key Findings

Initial exploratory analysis identified the following results:

Highest monthly sales: November 2017.

Average delivery time: Approximately 12.56 days.

Late delivery rate: Approximately 8.11%.

Five-star reviews: Approximately 57.8% of recorded review scores.

These findings are from the initial analysis and should be validated against the final calculations.

Business Value

This project demonstrates how data analysis and visualization can help businesses:

Monitor sales and order trends.

Track key performance indicators.

Understand customer satisfaction.

Prepare structured monthly MIS reports.

Identify potential business and operational improvement areas.
